# tanmoy-git.github.io

Redirects the old GitHub Pages addresses after the repos moved to the [tanmoy-bh](https://github.com/tanmoy-bh) organization:

- `/resume/*` to `https://tanmoybh.com/*`
- `/bobia/*` to `https://projects.tanmoybh.com/bobia/*`
- everything else to `https://tanmoybh.com/`

GitHub Pages serves `404.html` for any path without a file, and `redirect.js` maps the path.
